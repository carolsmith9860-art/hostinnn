# Dreams Couture 👗
A modern, responsive clothing store built with vanilla HTML, CSS, and JavaScript.

## Features
- Product catalog with categories & price sorting
- Shopping cart with localStorage persistence
- Fully responsive (mobile-friendly)
- Zero dependencies — deploy anywhere static

## Deploy on GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch / root → Save
4. Your store goes live at `https://<username>.github.io/<repo-name>/`

## Customize
- Add/edit products in `js/app.js` (`products` array)
- Swap `img` URLs for your own photos in `assets/img/`
- Colors live at the top of `css/style.css` (`#c9a24b` accent)
